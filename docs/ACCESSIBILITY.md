# CapExIQ — WCAG 2.2 AA Accessibility Compliance Document

## Accessibility Audit & Standards
1. **Color Contrast**: All light mode and dark mode text elements satisfy WCAG 2.2 AA minimum contrast ratio (4.5:1 for normal text, 3:1 for large text).
2. **Keyboard Navigation**: Full keyboard accessibility (`Tab`, `Shift+Tab`, `Enter`, `Space`, `Cmd+K` Command Palette, Arrow keys in Boardroom Presentation Mode).
3. **Screen Reader Support**: Semantic HTML tags (`<h1>`, `<nav>`, `<main>`, `<header>`), explicit `aria-label` attributes on icon buttons, and ARIA modal dialog trapping.
4. **Color Independence**: Status information always includes text labels alongside color badges (e.g. `Approve`, `Warning`, `Reject`).
