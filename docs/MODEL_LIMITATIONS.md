# CapExIQ — Model Limitations & Governance Disclosures

## Explicit Limitations & Boundaries
1. **Hypothetical Corporate Entity**: NovaRetail GCC is a hypothetical retail entity created solely for postgraduate corporate finance academic demonstration.
2. **DataCo Benchmark Scope**: Operational supply chain sample data (`01_dataco_supply_chain_sample.csv`) represents external operational metrics and must not be interpreted as NovaRetail historical financial statements.
3. **Deterministic Financial Calculation Isolation**: All NPV, IRR, MIRR, WACC, and payback calculations are generated strictly by deterministic TypeScript algorithms. AI LLM models generate advisory explanations only and have no capability to mutate financial calculations.
4. **Simplifying Assumptions**: Tax depreciation uses straight-line 5-year MACRS replacement schedules; DEWA electricity tariffs use commercial slab pricing.
